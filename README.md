# 返信ひと言（reply-drafter-x）

気になる人の投稿を貼って、気持ち（6種）と距離感（3段階）を選ぶと、返信の下書きを型の違う3案で出す静的ページです（100日100プロダクト Day070）。

- 標準では、貼った投稿と入力はブラウザの中だけで処理し、サーバーには送信せず、保存もしません（通信は閲覧数の計測のみ）
- 標準の下書きはAIを使いません（言葉拾いと言い回しの表の組み合わせだけ）
- 任意機能: PCのOllamaが使える環境では「AIで作り直す」が出ます（下の「Ollama強化モード」）
- 出力は句読点（。、）なしで、改行で区切ります。3案それぞれの文字数とユニット数を出します
- 相手の投稿の意味を理解して返しているのではありません。送る前に読み直して、自分の言葉に直してください

## 標準モード（ルールベース）の言い回し
- 気持ち6種×距離感3段階×スロット（書き出し・共感・言葉つきの一言・締め・気持ちの言葉・出来事）ごとに4種類以上の言い回しを用意（構文を変えてあり、言い換えだけではない）。表は `index.template.html` の `FEELINGS` と `Q` `QW` `QA` `QAW` `QA_TAIL` `NUMLINE` `VERB_OTHER`
- 投稿から次を機械的に拾い、ボタンで選び直せる: 「」・#タグ・目立つ言葉・数量（従来どおり）／**気持ちの言葉**（嬉しい・悔しい・不安・泣きそう・緊張・しんどい など24語を活用形つきの辞書で）／**出来事の動詞**（走りきった・続けている・受かった・落ちた・やめた など。ほめてよいもの/よくないものを分ける）／**質問の形**（？・でしょうか・ですか など。2案目を答えの形にする）。打ち消し・願望（〜たい）・仮定（〜たら）・依頼・「〜と言っていた」が続く言葉はなるべく拾わない（完全ではない）。重い気持ち（つらい・悔しい・不安 など）にはほめない専用の言い回しを使う。拾えなければ従来どおり
- 「3案まとめて別の言い方で」と「案Nだけ別の言い方で」: **乱数は使わず**、番号（シード・12通りで一巡）で決定的に巡回する。同じ投稿・同じ設定でも押すたびに言い回しが変わり、3案が同じ文・同じ書き出し（最初の4文字）にならないようずらす
- お礼は投稿の種類で言い回しが変わる: 教え・コツ・手順（「コツ・方法・手順・おすすめ」など）→「助かりました・参考になりました」／報告・近況→「聞けてよかった・知れて嬉しい」。画面のボタンで切り替え可
- 重い気持ち（つらい・悔しい・不安・泣きそう・緊張 など）は、好き・楽しいで受けず、なぞるだけの言い回しにする。返信する人の状態を作る文（心が軽くなった・元気をもらった 等）は使わない
- 重い話題（亡くなった・入院・離婚・事故 など）は、質問も感想も作らず、受け止める短い一言だけを出す。お祝いごと（合格・結婚・開業・出産・完走 など）は、お礼・感想・応援に「おめでとう」を足す。辞書にない出来事（引っ越し・退職 など）は読み取れない
- 質問の投稿への2案目は、共感・経験のとき以外は「同じ疑問があった」と言わず、「答えが知りたい」「いい答えが見つかりますように」型
- 短い投稿（24字まで）は、1行の短い一言に寄せ、拾った言葉は既定では入れない
- 3案の幅: 1行の案と2行の案が混ざる。数量・出来事が入りきらないときは3案目に回る
- 事実を作らない: 差し込むのは投稿にある言葉・数量・辞書の言い切りの形だけ。投稿にない数字や出来事は足さない。ただし「私にも覚えがあります」「知らなかったので」のように、使う人自身の気持ちや経験を述べる定型の文は入る（特に共感・経験の気持ち）。送る前に、自分に当てはまるか読んで直す前提
- 自然さは機械で保証できません。`node source/show-samples.js [シード...]` で架空の投稿の出力を一覧にして、読んで確かめます

## Ollama強化モード（任意・PC向け）
- 画面を開いたとき `http://localhost:11434/api/tags` を2秒だけ試し、使えれば「AIで作り直す」とモデル選択（既定 qwen2.5:7b）を出す。使えなければ折りたたみの案内（許可設定 `OLLAMA_ORIGINS` に **このページのアドレスだけ** を入れる手順）を出す
- 1回の呼び出しで3案を作り、後処理（句読点・記号の除去／NG語／数字と「」の語が元の投稿・メモ・言葉入力にあるかの事実ガード／長さ／距離感の簡易判定）を通った案だけ「AIの案」として出す。不合格が2案以上なら1回だけ再生成し、それでも不合格の案はルールベースの同じ型の案に差し替える
- 通信先は localhost:11434 だけ。履歴は保存しない。経過秒数の表示・中止ボタン・1回60秒で打ち切り
- Safari・iPhone・Androidでは動かない可能性が高い（https のページから http://localhost への通信）。モデルの文の品質は保証しない

## 使い方
`index.html` をブラウザで開きます。ビルド不要。

## 開発用
- `index.template.html` と `source/width-table.txt` から `python source/build.py` で `index.html` を作ります
- `node source/run-checks.js`: 生成部分の検算（言い回しの表の検査・全組み合わせ約2万件・気持ち/動詞/質問の拾い・ユニット数ほか）
- `node source/show-samples.js [シード...]`: 架空の投稿8種と6気持ち×3距離感の出力を一覧表示
- `node source/ui-check.js`: Chrome headless での画面の動作確認（Ollamaなしの従来動作）
- `node source/ui-check-ollama.js [--skip-timeout]`: 偽のOllamaサーバー（`source/fake-ollama.js`）での強化モードの画面確認。60秒打ち切りの確認は実時間で約1分かかる
- `node source/real-model-check.js [モデル名]`: 本物のOllamaで後処理の通過率と所要時間を記録（Originなしで直接呼ぶ。Ollamaの設定は変更しない）
- `node source/shoot.js <out>`: 投稿カード用の画面撮影
- `source/gen-width-table.py` / `source/gen-units-fixture.py`: ユニット数の表と固定サンプル（Pythonのunicodedata基準）
